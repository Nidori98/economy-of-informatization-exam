# Методология анализа

Для оценки влияния внедрения ERP-системы использован **парный t-критерий Стьюдента**.

### Почему выбран этот метод?
1. Выборки зависимые (одни и те же отделы до и после внедрения).
2. Позволяет оценить статистическую значимость различий средних значений.

### Критерий принятия решения:
- Если **p-value < 0.05**, нулевая гипотеза (H₀) отвергается. Различия значимы.
- Если **p-value ≥ 0.05**, нет оснований отвергать H₀. Различия могут быть случайны.
