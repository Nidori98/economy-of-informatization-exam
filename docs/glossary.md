# Глоссарий

- **ERP** (Enterprise Resource Planning) — система планирования ресурсов предприятия.
- **Выработка** — объём произведённой продукции или услуг на одного сотрудника.
- **Дисперсия (S²)** — мера разброса значений вокруг среднего арифметического.
- **p-value** — вероятность получить наблюдаемые (или более крайние) результаты при условии, что нулевая гипотеза верна.
